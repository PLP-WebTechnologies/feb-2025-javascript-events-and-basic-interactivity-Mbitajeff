# JavaScript Concepts Demonstration Webpage

## Overview

This project demonstrates three fundamental JavaScript concepts through an interactive webpage:

1. **Event Listeners**
2. **Form Validation**
3. **Interactive Elements**

The webpage features a clean, responsive design with dark/light mode toggle functionality.

## Features

### 1. Event Listeners Section
- **Color Selector**: Changes a box's color based on dropdown selection
- **Click Coordinates**: Displays mouse coordinates when clicking in the section
- **Keypress Counter**: Counts and displays each keypress in an input field

### 2. Form Validation Section
- **Registration Form** with validation for:
  - Username (minimum 4 characters)
  - Email (valid format)
  - Password (minimum 8 characters)
  - Password confirmation (must match password)
- Real-time error messages
- Success message on valid submission

### 3. Interactive Elements Section
- **Counter**: With increment, decrement, and reset functionality
- **To-Do List**:
  - Add new tasks
  - Delete tasks
  - Add tasks by pressing Enter key
- **Theme Toggle**: Switch between light and dark mode

## How to Use

1. Clone or download the repository
2. Open `index.html` in any modern web browser
3. Interact with the different sections to see the JavaScript concepts in action
